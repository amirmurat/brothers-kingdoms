## Outstanding scope

- **031:** Pixel-grid territory geometry still has visible stepped edges at some zoom levels. Vector borders improved, but the renderer isn't a true high-resolution contour mesh.
- **075:** Host migration is not supported; it needs secure state handoff or a dedicated always-on authoritative host. The game shows this limitation and provides guest reconnection to the *same* host instead.

## Partially addressed

- **005:** The attack forecast is only an approximate local defense estimate, not a simulation of the full campaign outcome.
- **030:** The HUD has been reduced and made collapsible, but visual density should be validated with users on small phones.
- **034/037/038/039/040:** Terrain contrast, markers, and army counts are improved, but a full accessible cartographic visual language remains future work.
- **044:** Troop limit and growth are exposed; a proper capacity progress bar is still missing.
- **063:** Players choose one of four quadrants rather than selecting any precise spawn point on the map.
- **066:** Invite links prefill the room and show a prominent Join action; no automatic room join, intentionally avoiding unexpected connections.
- **083:** Keyboard navigation and text descriptions are available, but a complete screen-reader spatial map requires additional testing and work.
- **091/093:** DOM updates are memoized and territory grid is delta-sent, while resource/UI snapshots and some widget redraws are still full updates.
- **099:** Important events generate alerts, but a comprehensive, user-tunable alert center has not been implemented.

## Verification caveat

The simulated PeerJS transport test verifies protocol integration, not real relay performance or hostile network conditions. Do not mark online stability as production-verified without two physical devices.
