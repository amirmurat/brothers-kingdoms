# Tiny Swords (original old CC0 edition)

Creator: **Pixel Frog** — https://pixelfrog-assets.itch.io/tiny-swords

The author offers an independent download named **`TS_old version_CC0 Licensed`** (2.6 MB). Only the original old edition is CC0; the current free/enemy packs have **different redistribution conditions** and are not imported here. See https://itch.io/e/19639933/pixel-frog-updated-tiny-swords and the author's download listing.

Sprite source in this integration: https://github.com/hoangpx/age-of-tinies/tree/master/art (older Tiny Swords layout with `Buildings/Blue Buildings/`, `Terrain/Tileset/`, `Pawn and Resources/`, and original UI). Source file PNG content has been imported unmodified. The old-pack archive itself was not available for byte-by-byte comparison, so consult the author's original ZIP for independent provenance verification.

Licensing: CC0 1.0 Universal **for old edition sprites only**. Attribution to Pixel Frog is included voluntarily. No assets from the new non-CC0 Free Pack are used.

Building visuals map to available *distinct* old-pack sprites, with gameplay labels disambiguating the historical art: farm → House1; lumber → House2; quarry → House3; mine → Monastery; barracks → Barracks; fort → Tower; city → Archery; capital → Castle. Artwork is decorative; no game rules change. The PNGs in this folder are first-party game assets served locally, not hotlinked.
