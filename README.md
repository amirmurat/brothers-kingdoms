# Brothers Kingdoms — Deep UX v13

Версия после системного аудита всех экранов v12 методом «вопрос → причина → действие → проверка». Главное внимание — состояния, которые прежде оставались оформленными в старом стиле, несмотря на игровой HUD.

## Изменения

- Раздельные итоги победы, поражения и ничьей с причиной, читаемой статистикой, повторным матчем и выходом.
- Новый компактный экран экономики: четыре узнаваемые иконки одинакового размера, остаток и доход, затем информация об армии.
- Карточки дипломатии стилистически согласованы со строительством; цвет державы не является единственным носителем значения, разрыв союза требует подтверждения.
- Улучшены список походов, пустое состояние, справка, вкладка «Обзор», кнопки, состояния фокуса, контраст.
- Ресурсные сетки строительства и исследований заполняют ширину; логика отображения ресурсов одинакова в меню и HUD.
- Сохранён исходный движок захвата из v12. Изображения — оригинальные; ассеты Clash of Clans не используются.

## Файлы

`index.html` + `game-v13.css` + `game.js` + `engine.js` и `assets/` — модульная сборка для правок. `standalone.html` — автономный HTML с inline CSS, JS и SVG; для сетевой игры по-прежнему запрашивает PeerJS через CDN. Именно содержимое `standalone.html` предназначено для GitHub Pages как корневой `index.html`.

`DEEP_UI_AUDIT.md` — глубокий аудит с реестром из 20 систем экранов, деревьями вопросов, таблицей приоритетов и критериями остановки. `UI_V13_STATUS.md` — что реально исправлено и что остаётся.

В браузерной среде используется загрузка inline HTML/CSS/JS, поскольку доступ к локальным URL ограничен. Это не полноценный Safari или интернет-тест.
