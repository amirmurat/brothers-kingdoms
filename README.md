# Brothers Kingdoms — Total Conquest v14

Браузерная стратегия для игры с братьями. Главное изменение v14 — новый режим «Полное завоевание».

- Победа только при контроле **100% суши**.
- Нет обратного отсчёта и окончания матча по времени.
- Порты, флот и морские высадки удалены.
- Карта генерируется в виде **одного связного материка**; все земли доступны с суши.
- Вместо таймера HUD показывает число активных фронтов.
- В новых сетевых комнатах **0 ботов по умолчанию**; одиночный матч — 4 бота.
- Семь полезных построек и три исследования; другие правила экономики, боя и дипломатии в основном сохранены.

Подробное объяснение и оставшиеся вопросы баланса — в [`RULES_V14.md`](RULES_V14.md).

## Запуск

- Через GitHub Pages — `https://amirmurat.github.io/brothers-kingdoms/?v=14` после публикации.
- `index.html` — автономная сборка; интернет нужен только для сетевой библиотеки PeerJS и многопользовательской игры.
- Исходники: `engine.js`, `game.js`, `game-v13.css`. Название CSS унаследовано, содержание обновлено для v14.

## Тесты

```bash
node test-rules-v14.js
python test-v14-flow.py
python test-v14-ui.py
python test-v14-network.py
```

Проверены 100 карт на связность, 180 стартов с 14 участниками, три полные партии ботов, достижение 100%, старый 12-минутный рубеж, невозможность морского захвата, отображение на четырёх экранах и комната двух игроков с имитированной сетью.

## Ограничения

- Старые одиночные сохранения v13 несовместимы с новой картой; v14 использует свой ключ сохранения.
- Автоматический перенос роли ведущего отсутствует.
- Игра между настоящими телефонами и запуск на Safari ещё требуют проверки.
