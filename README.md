# Brothers Kingdoms — Frontier v3 (performance & interface)

Бесплатная браузерная семейная стратегия на большой карте. **Прототип, а не готовый аналог Territorial.io.**

## Играть

GitHub Pages: https://amirmurat.github.io/brothers-kingdoms/

- «Играть против ботов» — запуск без регистрации.
- «Создать комнату» — ведущий присылает ссылку братьям. Пока играют до 4 человек плюс боты.
- Касание свободной или вражеской земли — отправка войск. Процент — снизу. Передвижение камеры — свайп, масштаб — pinch или кнопки.
- Кнопка «Развитие» — строительство, наука, дипломатия. Здание размещается касанием своей клетки.
- Кнопка «⛶» — весь мир; «◎» — собственная столица.
- Победа: захват 70% суши или лидерство по истечении 12 минут.

## Что изменилось в v3

1. Отрисовка карты: вместо создания canvas 2240×1456 и поштучного рисования всей карты на каждом обновлении — компактный 160×104 пикселя bitmap. Bitmap обновляется только при изменении владельцев клеток. Масштабирование — GPU canvas без сглаживания.
2. Миникарта: кэширование исходной картинки; на кадре обновляется только прямоугольник камеры.
3. Кэш границ территорий для ботов на один игровой тик (вместо многократного полного обхода сетки для каждой цели).
4. DPI canvas на мобильных ограничен до 1 для экономии памяти; на больших экранах — до 1.5.
5. По умолчанию раскрывается карта с понятной нижней панелью атак; на телефоне развитие вынесено в закрываемую боковую панель.
6. По сети неизменный рельеф отправляется при запуске игры, а не каждую секунду. Войска и владельцы клеток продолжают синхронизироваться.
7. Более связные биомы и узнаваемые области вместо случайной шахматной раскраски.

## Тесты

- `node test-engine.js` — экономика, атаки, постройки, дипломатия, инварианты владений (311 тиков).
- Chromium, 390×844: первый заход, захват клетки, рост территории через 8 тиков, постройка фермы, меню. Ошибок JS нет.
- Тест повторных обновлений рендера: v2 среднее 62 мс, v3 среднее 3.4 мс в headless Chromium на мобильном viewport; это стендовые цифры, **не измерение FPS на настоящем iPhone**.

## Архитектура

- Чистый HTML/CSS/JavaScript, Canvas 2D; без платных движков.
- `engine.js` — игровая логика, `game.js` — клиент и peer-to-peer соединения (PeerJS Cloud), `style.css` — интерфейс.
- GitHub Pages — публикация статики. Ведущий комнаты исполняет симуляцию.

## Известные ограничения

- Соединение между двумя реальными устройствами и поведение на iPhone требуется дополнительно проверить после обновления.
- Без выделенного сервера ведущий должен быть в сети. Синхронизация не защищена от жульничества ведущего, реконнекта и потери пакетов на уровне профессиональных RTS.
- Текущая механика армии и экономическая глубина заметно проще Territorial.io. Для уровня коммерческой игры потребуются балансировка, несколько вариантов карт, onboarding, устойчивое серверное состояние, matchmaking, более качественная графика и плейтесты.

В проекте нет копирования оригинального кода и ассетов сторонних игр.
