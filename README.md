# Brothers Kingdoms

Бесплатная браузерная RTS для 2–4 друзей или братьев. В одной комнате все действия игроков происходят одновременно. Первая играбельная альфа (v0.1).

## Возможности

- Карта 24×16 со случайным рельефом, лесами, камнем и водой.
- До 4 разных королевств; территория определяется влиянием ратуш и форпостов.
- Добыча древесины и камня рабочими (выбрать рабочего, нажать на лес/камень).
- Пассивное производство еды фермами и золота ратушей.
- Фермы, дома, казармы, башни, форпосты; улучшение зданий до 3-го уровня.
- Наём рабочих и воинов; перемещение и атака по клику.
- Башни автоматически обстреливают врагов, юниты защищаются рядом с собой.
- Побеждает игрок, сохранивший последнюю ратушу.
- Онлайн-комнаты peer-to-peer через бесплатный PeerJS Cloud, плюс офлайн-демо с ботом.

## Запуск

1. Поместите `index.html`, `style.css`, `engine.js`, `game.js` в корень **нового публичного GitHub-репозитория**.
2. В GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
3. После публикации откройте появившийся URL GitHub Pages.
4. Создатель комнаты вводит имя и жмёт «Создать комнату». Отправляет братьям ссылку. Когда 2–4 игрока зайдут, нажимает «Начать матч».
5. Не закрывайте вкладку ведущего до конца матча.

Для локальной проверки достаточно открыть `index.html` в браузере. Для онлайн-игры потребуется доступ к PeerJS Cloud; GitHub Pages служит статическим хостингом.

## Управление

- **Нажатие по своему юниту** — выделить юнита; затем **по земле** — переместить, **по лесу или камню** — добывать (только рабочий), **по врагу** — атаковать.
- **Кнопка здания → клетка своей территории** — построить здание, если достаточно ресурсов.
- **Рабочий / Воин** — нанять юнита (воинам нужны казармы).
- **Нажатие на своё здание → Улучшить** — усилить здание.
- **Esc** — сбросить выбор.
- На мобильном карту можно прокручивать.

## Архитектура

- `engine.js` — независимый игровой движок, работающий на хосте; команды проверяются движком.
- `game.js` — отрисовка и управление, соединения через PeerJS.
- `index.html`, `style.css` — интерфейс без сборки и зависимостей на npm.

PeerJS использует бесплатный общий сигналинговый сервер. Это экспериментальная инфраструктура: некоторые мобильные сети, NAT или блокировки WebRTC препятствуют соединению, и бесплатный сервер не гарантирует доступность. Без специального TURN-сервера соединение может не установиться. Ведущий должен оставаться в игре; состояние **не сохраняется** при перезагрузке страницы. Комнаты не защищены паролем. Не используйте такой прототип для публичных матчей с незнакомыми людьми.

## Ограничения первой версии

Строительство мгновенное; карта небольшая; нет аккаунтов, сохранений, дипломатии, дипломатических альянсов и восстановления сессии. Экономика и баланс предварительные. Бот — простой противник только для демо. Требуется тестирование соединения на нескольких реальных телефонах.

## Бесплатность

- Клиент и игровой движок: чистые HTML, CSS и JavaScript, без платных сервисов.
- Хостинг: GitHub Pages для публичных репозиториев в GitHub Free.
- Сигналинг: общий PeerJS Cloud (бесплатный, без SLA).
- Графика рисуется Canvas, никаких платных ассетов.

Неофициальный семейный проект. Все игровые механики оригинальны; не использует чужие изображения, персонажей или товарные знаки.
